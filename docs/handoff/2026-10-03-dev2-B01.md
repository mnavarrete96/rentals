## Decisiones tomadas y por qué
- **Spring Boot 4.1.0** (no 3.5.x): la versión GA existe en Spring Initializr. Cumple con ARCHITECTURE §4.1 ("línea 4.0.x").
- **`spring-boot-starter-webmvc`** en lugar de `spring-boot-starter-web`: Spring Boot 4.x renombró este starter. Verificado descargando proyecto de `start.spring.io` con `bootVersion=4.1.0&dependencies=web`.
- **`spring-boot-starter-flyway`** en lugar de `flyway-core` directamente: Spring Boot 4.x introdujo un starter para Flyway. `flyway-database-postgresql` sigue siendo dependencia separada (sin starter propio).
- **No se incluyeron starters de security**: según la tarea B-01, estos van en B-06.
- **`WebMvcConfigurer` para CORS**: implementación directa en `CorsConfig` (no `@Bean` separado) para mantener la clase autocontenida y legible.

## Problemas conocidos / riesgos
- `.env.example` no pudo crearse (permisos). El usuario lo crea manualmente con el contenido de §Qué falta.
- `./gradlew build -x test` compila en verde pero el app no arrancará sin una BD real y las variables de entorno `DB_URL`, `DB_USERNAME`, `DB_PASSWORD` definidas.
- Spring Boot 4.x puede tener cambios de API respecto a 3.x (paquetes Jakarta EE 11). Verificar al añadir dependencias en B-02 a B-06.
