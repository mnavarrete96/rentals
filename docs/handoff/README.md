# Notas de traspaso

Cada vez que un agente termina o se detiene, deja aquí una nota para que el siguiente continúe sin
preguntar nada.

- **Nombre del archivo:** `AAAA-MM-DD-<agente>-<ID-tarea>.md` (por ejemplo, `2026-10-03-dev1-T-01.md`).
- **Plantilla:** `docs/templates/handoff.md`.
- Las notas no se borran: son el historial de por dónde pasó el trabajo.
