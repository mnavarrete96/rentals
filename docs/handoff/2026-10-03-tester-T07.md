## Dónde continuar (el siguiente agente empieza aquí)

dev1: añadir las siguientes dos reglas CSS al final de `src/css/styles.css`,
en la sección "Correcciones / clases generadas por render.js" o en una nueva
sección de overrides de hover:

```css
/* Preservar borde acento en tarjeta activa al hacer hover */
.card--active.card--clickable:hover {
  border-color: var(--color-accent);
}

/* Preservar borde acento en selector de arrendatario activo al hacer hover */
.tenant-selector-btn--active:hover {
  border-color: var(--color-accent);
}
```

**Por qué:** `.card--clickable:hover` tiene especificidad 0-2-0 y
`.card--active` tiene 0-1-0. Sin las reglas de override, al hover sobre
un elemento activo, `border-color` pasa de `--color-accent` (#4f8ef7)
a `--color-border-hover` (#3d4565), borrando el indicador azul activo.
El mismo conflicto afecta a `.tenant-selector-btn--active` vs
`.tenant-selector-btn:hover`.
