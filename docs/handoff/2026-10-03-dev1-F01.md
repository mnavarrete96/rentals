## Decisiones tomadas y por qué
- `--font-body` añadida como custom property en tokens.css: facilita su uso en Vue sin hardcodear el stack.
- `base.css` separado de `tokens.css`: los tokens son valores; base.css aplica estilos globales (SRP).
- `formatMonth` usa `toLocaleDateString('es-EC', { month: 'long', year: 'numeric' })`:
  formato natural en español de Ecuador, coherente con la zona horaria America/Guayaquil del proyecto.
- Stores y api con estructura mínima exportada: F-02 implementa sin cambiar import paths.
- Sin `npm create vite` interactivo: estructura creada manualmente para control total.
